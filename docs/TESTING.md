# 시험평가서를 웹 명령 센터로 하는 법

두 시험평가서(「비상정지 및 오류 복귀 성공률」, 「음성 기반 작업 수행 성공률」)를 이 웹 페이지로 진행하는 방법입니다. 2026-11-21 기준.

**안전:** 바퀴 시험은 처음에 로봇을 받침대에 올려 바퀴가 뜬 상태로 합니다. 시험원 2명(조작 1, 계측 1)이 있을 때만 움직입니다.

## 0. 시험 전에 한 번만

| # | 할 일 | 왜 |
|---|---|---|
| 1 | 두 브랜치를 합친 코드로 서버를 다시 시작 (`./run.sh robot`) | 아래 기능이 모두 이 코드에 있음 |
| 2 | 라이다를 최종 위치에 고정 → Studio **라이다 설정** 실행 (앞 방향 + 로봇 자신 마스크, 장애물 정지 켜짐) | E4·E4′·R3. 마스크가 있어야 가림·접촉 정지가 다시 켜짐 |
| 3 | (선택) 탑뷰 카메라 복구 도우미 설치: `deploy/README.md` 6b 단계 (sudo) | R6 의 **탑뷰 카메라 복구** 버튼 |
| 4 | 음성 탭 **한 번 이동량**을 **0.2 m · 45° (시험)** 으로 | 음성 시험 4.1 |
| 5 | System 탭 **정지 측정 → 지우기** | 이번 시험의 측정만 남기기 |

기록은 자동으로 남습니다: `~/so101/logs/web_<프로그램>_<시각>.log` (줄마다 ms 시각), `base_teleop_<시각>.log`, 팔 관절각 `web_joints_<시각>.csv`, 정지 측정 CSV (System 탭 **CSV**).

## 1. 비상정지 (E1~E7)

정지할 때마다 System 탭 **정지 측정** 표에 한 줄이 생깁니다: 시험 번호, 명령이 0 이 될 때까지(초), 멈출 때까지(초), 정지 거리, 5초 동안 밀림, 판정(✓/✗). 줄자 측정은 그대로 하고, 표의 값은 로봇 오도메트리 기준 참고값입니다.

| 번호 | 페이지에서 | 성공 기준 | 표에 나오는 이름 |
|---|---|---|---|
| E1 게임패드 데드맨 | 로봇 게임패드: LB 누르고 0.2 m/s, LB 떼기 (터보 버튼은 없어짐). 노트북 게임패드·키보드도 같음 | 0.5 s 이하, 10 cm 이하 | 로봇 게임패드 LB / 페이지 데드맨 |
| E2 음성 정지 | 음성 탭: "전진" 뒤 이동 중 누르고 "정지" | 1.0 s 이하, 10 cm 이하 | 음성 정지 |
| E3 스택 정지 | 주행 탭 베이스 **끄기** | 2 s 이내 정지, 바퀴 토크 OFF (손으로 돌려 확인) | 베이스 끄기 |
| E4 라이다 가림 | 0.1 m/s 주행 중 손으로 라이다를 덮기 | 0.5 s 이하 | 라이다 가림 |
| E4′ 스캔 끊김 | 라이다 USB 뽑기 | 1.0 s 이하 | 라이다 스캔 없음 / 라이다 끊김 (페이지) |
| E5 원격 데드맨 | 팔 탭 **리더 팔 사용**(노트북 Web Serial)으로 움직이다 노트북 Wi-Fi 끄기 | 1.0 s 이하 정지, 낙하 없음 | 리더 연결 끊김 |
| E6 팔 전체 정지 | 텔레옵 중 **텔레옵 끄기** (또는 E-STOP: 팔을 잡고 2초 뒤 접음. 접지 않으려면 `KIRO_ESTOP_FOLD_S=0`) | 2 s 이내 종료, 낙하 없음 | 텔레옵 끄기 |
| E7 전원 차단 | 휠 12 V 스위치 (참고) | 파손 없음, R2 로 복귀 | - |

## 2. 오류 복귀 (R1~R8)

| 번호 | 오류 주입 → 페이지에 보이는 것 | 복귀 |
|---|---|---|
| R1 팔 USB 분리 | 팔 탭에 "USB 보드가 빠졌거나 응답이 없습니다" | 다시 꽂고 **텔레옵 켜기**. 켜기 전에 모터 목표를 현재 자세로 맞춰 튀지 않음 |
| R2 휠 12 V 끔 | 1초 뒤 바퀴 노드가 "응답 없는 서보 … 12 V" 로 끝남 → 주행 탭 "바퀴 응답 없음" | 12 V 켜고 베이스 끄기 → 켜기. 주행 탭에 "바퀴 오도메트리 20 Hz" |
| R3 라이다 분리 | 0.5 s 안에 정지, "라이다 끊김: 모두 정지" | 다시 꽂기. 5초 넘게 스캔이 없으면 서버가 베이스를 스스로 다시 켬 (아니면 끄기 → 켜기). 라이다 없이 켜려 하면 거부 |
| R4 음성 노드 강제 종료 | 음성 탭에 끝난 이유 | **음성 켜기** 후 "정지" |
| R5 원격 노트북 끊김 | 팔은 그 자리 유지, 페이지 "로봇과 연결이 끊겼습니다" | Wi-Fi 복구 → PIN 으로 제어권 → 리더 팔이 자동으로 다시 켜지고 40°/s 로 이어서 따라감 |
| R6 탑뷰 카메라 소실 | Studio 카메라 표에 이유 (예: 컬러 화면 없음) | Studio **탑뷰 카메라 복구** → 검증 마법사 카메라 단계(UVC)에서 20 fps 이상 확인 |
| R7 녹화 강제 정지 → 이어서 | Studio 확인 단계에 "데이터셋 읽기 정상: 에피소드 n개" 또는 "망가짐 + 이전 사본" | **더 녹화** (기존에 추가) |
| R8 텔레옵 SIGKILL | 팔 탭 "예기치 않게 끝났습니다. 팔은 마지막 자세 유지" | **풀기** 또는 바로 **텔레옵 켜기** (목표 동기화로 튀지 않음) |

## 3. 음성 시험

| 항목 | 방법 |
|---|---|
| 사전 자체 시험 (5.1) | `cd ~/so101/ros2/so101_base && PYTHONPATH=. python3 so101_base/voice_cmd.py --selftest-phrases --selftest-noise` → "모두 통과" (명령 21개 + 대화 소음 8개) |
| 명령 1~6 | 음성 탭 **누르고 말하기** 를 누른 채 한 번 말하고 떼기. 손을 뗄 때 판정합니다 |
| 정지 7 | 이동 중 누르고 "정지"/"멈춰". 말하는 도중에 바로 멈춥니다 (버튼을 계속 눌러도) |
| 기록 | 음성 탭 목록: [들림] 문구·신뢰도, [실행], [완료] 줄에 odom 이 잰 거리·옆 밀림·방향 |
| 소음 (표 3) | 대화 소리만 틀고 누르기 30회 → [실행] 0 |

음성 판정 규칙 (2026-11-20 바뀜):

- 한 번 누른 동안 들린 것 **전체가 정해진 문구 하나**일 때만 움직입니다. 대화 소리는 여러 문구 낱말이 섞여 나와서 움직이지 않습니다.
- 방향 한 마디(앞으로·뒤로·왼쪽·오른쪽)는 움직이지 않고 "'앞으로 가' 라고 말하세요" 안내만 합니다. 권장 문구(전진, 앞으로 가, 후진, 뒤로 가, 왼쪽으로 가, 오른쪽으로 가, 좌회전, 우회전, 정지, 멈춰)는 모두 됩니다.
- 정지어가 들어 있으면 다른 문구보다 항상 이깁니다.
