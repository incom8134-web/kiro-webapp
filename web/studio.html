The robot cannot train. Google Colab trains on a free Google graphics card, then the model comes back here.

    

      

        
The robot sends the dataset to Google Colab, which trains it on a free GPU, and brings the trained model back by itself. The robot needs internet (its LAN cable).

Trained models

      
Download policy saves a zip of the trained model. The file is named <name>_pretrained_model.zip and holds one folder, pretrained_model/. Unzip it to ~/policies/<name>/ so that folder is ~/policies/<name>/pretrained_model/. To run it on a loop, open the control page, Arms tab, choose that model, set Runs and press Play. On the robot: for i in 1 2 3 4 5; do ~/so101/run_policy.sh run ~/policies/<name>/pretrained_model 30; sleep 5; done
