    Setup

    The Matek board is a TI INA228. It measures voltage, current, power, energy, charge and the chip temperature. It does not measure percent, health or cycles. This page estimates those three.

    Wire the board to the Jetson 40-pin header.

    5 VJetson pin 2 or pin 4. The board needs 4-9 V.
    GroundJetson pin 6.
    SCLJetson pin 5 (I2C clock).
    SDAJetson pin 3 (I2C data).

    The address jumpers select 69 (the default), 68 or 65. Pins 3 and 5 are usually bus /dev/i2c-7. If the board is on another bus, set KIRO_BATT_I2C_BUS.

    Set these before starting the server. Chemistry is lipo, li-ion or lifepo4. The pack numbers are an example, not a measurement of this robot. KIRO_BATT_CYCLE_LIFE is the maker's cycle life: it is saved with the battery notes and is not a measurement.

    KIRO_BATT_I2C_BUS=7
KIRO_BATT_I2C_ADDR=69
KIRO_BATT_CHEMISTRY=lipo
KIRO_BATT_CELLS=4
KIRO_BATT_CAPACITY_AH=10
KIRO_BATT_CYCLE_LIFE=500

    Wire IN+ toward the battery and IN- toward the robot, so a positive current means the pack is discharging. Percent starts from the voltage while the current is near zero, then follows the charge the chip has counted. Energy and charge on the chip start again at zero if the board loses power. Cycles and health stay in a file on the Jetson. On the robot, install smbus2 (pip install smbus2) and let this user read I2C.
